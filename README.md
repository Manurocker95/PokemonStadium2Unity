# PokemonStadium2Unity

Port of model extractor from: https://github.com/DramaticShape/DramaticShapeVoxelMod/tree/dev/model_extract/pipeline to be usable in Unity Engine 5.6+ with just one click. 


You can import meshes, animations, textures separately, auto-create the prefab and generate static or skinned meshes without leaving the editor. You need to use a USA 1.0 ROM like the original project. Open the tab with VirtualPhenix > Pokemon Stadium 1 > Importer

Select the index (or all) you wanna import and click on import.
